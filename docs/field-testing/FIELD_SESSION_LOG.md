## How to use

1. Copy the **Session template** block below.
2. Paste it under [Sessions](#sessions) as the newest entry.
3. Fill the header, summary, checklist, defects, performance, and feedback.
4. Give a **Release Recommendation** with justification.
5. Log any full bug in `06 - BUG_TEMPLATE.md` and reference it here.

Severity scale (same as the rest of the pack): **Blocker** · **Major** ·
**Minor** · **Suggestion**. Only Blockers/Majors are fixed during the pilot.
