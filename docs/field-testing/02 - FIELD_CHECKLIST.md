## Inspection flow

- [ ] **Login (or DEV MODE)** — app opens; you are identified as the inspector.
- [ ] **Create inspection** — a new inspection is created and gets an ID.
- [ ] **Client information** — client name / contact entered and saved.
- [ ] **Property information** — address / property details entered and saved.
- [ ] **Import PDF** — property/inspection PDF imported without error.
- [ ] **Import photos** — one or more photos imported and visible.
- [ ] **AI analysis** — analysis runs and returns observations.
- [ ] **Review observations** — AI observations are readable and make sense.
- [ ] **Add manual observations** — you can add your own observations.
- [ ] **Generate PDF** — a report PDF is produced.
- [ ] **Verify PDF** — the PDF opens and content is correct.
- [ ] **Save inspection** — the inspection is saved.
- [ ] **Reopen inspection** — close and reopen; the inspection loads.
- [ ] **Verify persistence** — all entered data / photos / observations are still there.
- [ ] **End inspection** — inspection marked complete / closed.
